# Model Artifacts

This directory contains trained models and optimized artifacts generated by the Python training and quantization pipeline.

## File Descriptions

| File | Type | Description | Target Environment |
| :--- | :--- | :--- | :--- |
| `model.tflite` | TFLite Model | Unquantized floating-point TFLite model | Host / Python evaluation |
| `model_quant.tflite` | TFLite Model | Post-training INT8 quantized model | Embedded / TFLite Micro |
| `model_data.h` | C Header | C byte array representation of `model_quant.tflite` | C++ TFLM runtime (`main.cpp`) |

## Quantization Summary

- **Precision:** Full INT8 (Inputs, Outputs, and Weights)
- **RAM/Flash Savings:** ~75% reduction compared to FP32 baseline
- **Optimization Strategy:** Dynamic range calibration via representative dataset
